# 知识库

本知识库按六个月学习路线的六个阶段组织。每个阶段对应一个目录：

- 目录中的 `README.md` 为该阶段的**知识清单**，列出需要掌握的全部知识点，已掌握的条目打勾并链接到对应笔记；
- 每个知识点在实际用到时写成一篇独立笔记。

## 写作规范

1. **以真实代码为依据**：只记录本仓库实际使用到的知识，每个论点都注明出处（文件与行号）；
2. **及时性**：项目中引入新知识点的当天补写笔记；未实际使用的条目保持未勾选状态，不预先摘抄教程内容；
3. **可自检**：每篇笔记末尾附自测题，间隔数日后在不查看原文的前提下作答，未能作答的部分重新阅读代码。

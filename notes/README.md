# 知识库 · 六阶段知识地图

按 6 个月学习路线组织，共六个阶段。每个阶段一个目录：

- 目录里的 `README.md` 是该阶段的**知识清单**——要掌握什么，一目了然，学完打勾 ✅
- 每个知识点学到时写成一篇独立笔记，从清单链接过去

写笔记的三条约定不变：

1. **只记本仓库真实用到的知识**，每一条都能指到具体文件和代码行
2. **用到新东西的当天就补**，哪怕只有三行；清单上没学到的项保持未勾选，不抄教程凑数
3. 每篇末尾放**自测三问**，隔几天回来不看答案自答一遍
